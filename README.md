### Исправления
- Пересобрана нижняя информационная панель: цифры выровнены по центрам значков батареи, шагов, пульса и погоды.
- Увеличены центральные цифры времени.
- Отображение погоды: прогноз **минимальной/максимальной** температуры за день (при наличии погодных данных Zepp), не текущая фактическая температура.
- Включён `lockscreen:1` для собственного AOD, добавлены цифровое время, дата и логотип. На часах может потребоваться выбрать режим AOD, следующий за текущим циферблатом.
- Сохранена исправленная иллюстрация буровой со штангой от бурового узла.

**Статус:** Zeus CLI собрал пакет, архив проверен. Установка/поведение версии 1.0.4 на реальных часах пока не проверены.

Старые ZPK оставлены для истории и восстановления, но для тестирования используйте только актуальную версию.
