### Что исправлено

1. Новая иллюстрация на всю площадь 480×480 без старых неправильных обрезок. Буровая штанга выходит из переднего бурового узла, не из гусеницы.
2. У изображения задано `auto_scale: true` и `auto_scale_obj_fit: true`, чтобы совпадало с координатной сеткой элементов.
3. Время, дата и данные датчиков размещены под статическими элементами.
4. Созданы отдельные виджеты AOD с `show_level: ONAL_AOD` вместо условия `getScene()`.

**Внимание:** успешная сборка не гарантирует правильное отображение на реальных часах. Требуется тест на Amazfit Balance 2. Если опять будет смещение, пришлите фото циферблата на часах для дополнительной диагностики.

**Старый файл `DEAL_GNB_Balance2_TEST.zpk` не устанавливайте.** Он сохранён только как источник исходных ресурсов для сборки.
