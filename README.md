### Изменения v1.0.5
- Увеличен масштаб графики циферблата внутри физического экрана 480×480.
- Перерисована нижняя панель с компактными значками и значениями: заряд, шаги, пульс, температура.
- Прогнозный Weather-сенсор заменён на **системный** виджет температуры `TEXT_IMG` с `WEATHER_CURRENT` и собственными цифрами.
- Новый AOD: крупное время, логотип, дата, тонкий фирменный контур и стилизованный элемент ГНБ на чёрном фоне.
- Сохранён выход штанги из бурового узла, а не из гусеничной ходовой.

**Статус:** официальная компиляция Zeus успешна; ZPK прошёл проверку ZIP-архива и содержимого. Поведение новых элементов на реальных часах (особенно погода) требует проверки пользователем. Если погода снова пуста, проверьте синхронизацию погоды в Zepp и сообщите об этом для дальнейшей диагностики.

Старые файлы ZPK оставлены для истории, устанавливайте только 1.0.5.
