### Внешний вид
- Основной циферблат **точно такой же, как v1.1.3**, включая жёлтую ГНБ-установку. Сборка сравнивает его изображение на уровне пикселей.
- В режиме AOD: DEAL_ жёлтый, ГНБ белый, крупные контурные цифры времени белые.
- Дата жёлтая и смещена левее; справа новая жёлтая температура улицы с °. День недели белый.
- Температура связана напрямую с погодным прогнозом Zepp (WEATHER_CURRENT), без дополнительного сетевого обращения или секундного таймера.
- Родной системный IMG_TIME в обоих режимах сохранён, чтобы время не отставало после AOD.

### После установки
Нужно проверить, отображается ли температура на физических Amazfit Balance 2 в AOD, обновляется ли прогноз в Zepp, не отстаёт ли время и каков расход батареи. Сборка в GitHub не гарантирует поведение прошивки часов.
